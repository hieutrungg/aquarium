# T-001: Bộ công cụ asset pixel art (normalize + QA + Aseprite script)

## Bối cảnh
Dự án AquaVerse (đọc `plan.md` mục 5, 7). Ảnh cá do AI sinh ra ở `art/raw/*.png`, thường là "giả pixel art": kích thước ~1024px,
mỗi pixel logic là một khối ~16×16 nhưng lưới có thể lệch vài px, màu bị nhoè ở biên khối, và nền thường là **trắng/xám đặc
hoặc ô bàn cờ xám-trắng giả trong suốt** thay vì alpha thật. Cần công cụ đưa chúng về sprite pixel art sạch.
Máy KHÔNG có Python. Dùng **Node.js (v25, ESM)**. Palette chuẩn: `art/palette/aquaverse.gpl` (định dạng GIMP palette, 44 màu).

## Việc cần làm
Tạo thư mục `tools/` là một package Node riêng:

1. `tools/package.json` — `"type": "module"`, dependency duy nhất: `pngjs`. Scripts:
   `normalize`, `qa`. Chạy `npm install` trong `tools/`.
2. `tools/lib/palette.mjs` — đọc file `.gpl` → mảng `{r,g,b,name}`; hàm `nearest(rgb)` dùng khoảng cách màu cảm nhận
   (CIE Lab ΔE76 hoặc redmean).
3. `tools/sprite-normalize/index.mjs`
   CLI: `node sprite-normalize/index.mjs --in <raw.png> --out <out.png> --canvas 64 [--cell auto|<n>] [--palette ../art/palette/aquaverse.gpl] [--padding 4] [--max-colors 16]`
   Các bước:
   a. **Tách nền**: nếu ảnh có alpha thật thì dùng alpha (ngưỡng ≥128 → giữ). Nếu không, flood-fill từ 4 cạnh ảnh để loại
      các vùng nền liên thông có màu gần màu nền (ước lượng từ các pixel viền; hỗ trợ cả nền bàn cờ 2 màu sáng). Dung sai cấu hình được `--bg-tol` (mặc định 24).
   b. **Dò kích thước ô (cell)**: `auto` = ước lượng bằng phân tích độ dài các đoạn màu đồng nhất theo hàng/cột (lấy ước số chung phổ biến nhất,
      trong khoảng 4–32px), cùng với độ lệch gốc (offset) của lưới. Cho phép ép bằng `--cell 16`.
   c. **Lấy mẫu**: mỗi ô lưới → 1 pixel, màu = màu xuất hiện nhiều nhất trong vùng lõi 60% giữa ô (bỏ biên để tránh màu nhoè).
      Ô có > 50% pixel là nền → trong suốt.
   d. **Ép palette**: mỗi pixel → màu gần nhất trong palette. Nếu số màu > `--max-colors`, gộp các màu ít dùng nhất vào màu gần nhất còn lại.
   e. **Cắt & căn giữa**: crop theo bbox phần không trong suốt, đặt vào canvas `--canvas`×`--canvas` căn giữa (làm tròn xuống), báo lỗi
      (exit code 2) nếu bbox + padding không vừa canvas.
   f. Xuất PNG RGBA alpha chỉ 0/255. In ra JSON tóm tắt: `{cell, offset, logicalSize, bbox, colors, warnings}`.
   Cũng xuất kèm `<out>.json` chứa tóm tắt đó + `pivot` = tâm bbox.
4. `tools/sprite-qa/index.mjs`
   CLI: `node sprite-qa/index.mjs --dir ../art/export/fish [--palette ...] [--max-colors 16] [--padding 4] --report <out.json> --sheet <contact.png>`
   Với mỗi PNG: kiểm tra (1) mọi pixel nằm trong palette, (2) alpha chỉ 0/255, (3) số màu ≤ max, (4) padding ≥ min ở cả 4 cạnh,
   (5) canvas là 64×64 hoặc 96×96. Kết quả PASS/FAIL từng mục trong report JSON; exit code 1 nếu có FAIL.
   **Contact sheet**: mỗi sprite một hàng gồm: ảnh 1× trên nền `#B8E1D5`, ảnh 4× (nearest) trên nền `#B8E1D5`, silhouette 4× (tô `#35574F`) trên nền `#F9F5E9`,
   ảnh 1× trên nền `#76B5A5`. Khoảng cách giữa ô 8px, nền tổng `#EAF6F2`.
5. `tools/aseprite/normalize.lua` — script cho Aseprite CLI:
   `aseprite -b <in.png> --script-param palette=<gpl> --script-param out=<file.aseprite> --script tools/aseprite/normalize.lua`
   Mở sprite đang active, nạp palette từ file `.gpl` (`Palette{ fromFile = ... }`), chuyển sang ColorMode.INDEXED không dithering,
   lưu ra `out` (.aseprite). In lỗi rõ ràng nếu thiếu tham số.
6. `tools/README.md` — cách dùng 3 công cụ + lệnh export sheet Aseprite:
   `aseprite -b art/source/fish/*.aseprite --sheet art/export/fish/fish_sheet.png --data art/export/fish/fish_sheet.json --format json-array`
7. Test tự động `tools/test/run.mjs` (chạy bằng `npm test`): tự tạo bằng code một ảnh giả 1024×1024 (sprite 64×64 logic phóng 16×,
   lưới lệch 3px, nền trắng, thêm nhiễu ±6 ở biên khối), chạy normalize → khẳng định kết quả khớp sprite gốc ≥ 98% pixel.
   Thêm case nền bàn cờ.

## Không được làm
- Không sửa gì ngoài `tools/`.
- Không thêm dependency ngoài `pngjs` (không sharp, không canvas native).
- Không tải gì từ internet ngoài `npm install pngjs`.

## Nghiệm thu
- `cd tools && npm install && npm test` → pass.
- `node sprite-normalize/index.mjs --help` và `node sprite-qa/index.mjs --help` in hướng dẫn.
- Code có comment ngắn tiếng Việt hoặc tiếng Anh ở các bước chính.
