# T-004: Khung dự án Godot 4.7 + trang React nhúng bể

## Bối cảnh
Đọc `plan.md` mục 0, 3, 8, 9.2, 9.3. Godot 4.7 tại `D:\GoDot\Godot_v4.7-stable_win64.exe`, export templates 4.7.stable đã cài.
Frontend React + Vite + Tailwind ở `frontend/`. API `GET /api/tanks/:id` trả `{ tank, livestock, plants, hardscape, waterLogs, careTasks }`
(xem `backend/src/controllers/tankController.js`). Phase 0 chỉ cần khung chạy được end-to-end; chưa có sprite thật.

## Phần A — Godot (`game/`)
1. `game/project.godot`: tên "AquaVerse Tank", renderer **gl_compatibility** (cả desktop & mobile), viewport 640×360,
   window override 1280×720, stretch mode `viewport`, aspect `keep`, **scale mode `integer`**, default texture filter **Nearest**,
   snap 2D transforms/vertices to pixel = on, nền clear color `#EAF6F2`.
   Autoload: `Bridge` (`scripts/autoload/Bridge.gd`), `SceneState` (`scripts/autoload/SceneState.gd`).
2. `game/scripts/autoload/Bridge.gd`:
   - Nếu `OS.has_feature("web")`: dùng `JavaScriptBridge` đăng ký listener `message` trên `window` (giữ reference callback để không bị GC),
     parse `event.data` (object `{type, payload}`), chỉ nhận từ `window.parent` cùng origin (`event.origin === window.location.origin`).
     Khi sẵn sàng gửi `{type:"ready", payload:{version:1}}` lên `window.parent.postMessage(..., window.location.origin)`.
     Hàm `send(type, payload)` dùng chung.
   - Nếu không phải web: sau 1 frame tự đọc `res://data/dev/sample_scene_nature.json` và phát như nhận `scene:load`.
   - Signal `scene_loaded(dto: Dictionary)`, `message_received(type, payload)`.
3. `game/scripts/autoload/SceneState.gd`: giữ DTO hiện tại, hàm tiện ích `scene_size()` trả Vector2 theo quy tắc:
   chiều cao cảnh 300px, rộng = `300 * length / height`, clamp 400–1200 (thiếu dữ liệu → 600×300).
4. `game/data/dev/sample_scene_nature.json`: DTO đúng mẫu ở plan.md mục 9.2 (bể Nature 60×30×36, 12 neon_tetra, 1 betta, 2 angelfish, 8 guppy, 6 panda_cory).
5. `game/scenes/main.tscn` + `scripts/Main.gd`: cây node:
   `Main (Node2D)` → `Camera2D` · `TankView (Node2D, scripts/tank/TankView.gd)` · `HUD (CanvasLayer)` có 1 Label trạng thái + 1 Button "Cho ăn" (chưa cần logic, chỉ in log).
6. `scripts/tank/TankView.gd`: khi `scene_loaded`, dựng tạm bằng hình học (vẽ trong `_draw`, không dùng asset):
   tường `#76B5A5` phủ toàn khung, khối nước `#B8E1D5` kích thước `scene_size()` căn giữa theo chiều ngang,
   viền kính 2px `#35574F`, dải nền cát `#E8D9B5` cao 24px ở đáy nước, mặt nước 1px `#D6F0E8`.
   Spawn mỗi con cá trong `livestock` (tổng quantity, cap 120) là node `PlaceholderFish` (`scripts/fish/PlaceholderFish.gd`):
   nếu tồn tại `res://assets/fish/<speciesKey>.png` thì dùng Sprite2D texture đó, ngược lại vẽ hình thoi 12×6 màu theo hash speciesKey từ palette.
   Cá bơi ngẫu nhiên (wander, đổi hướng thì flip_h), giữ trong tầng theo `render.swimZone` (top 0–35%, mid 25–75%, bottom 75–95% chiều cao nước),
   vị trí làm tròn về số nguyên pixel khi vẽ.
   Camera: nếu cảnh rộng hơn 640 thì kéo ngang bằng chuột trái giữ hoặc phím ←→, giới hạn trong cảnh.
   HUD Label hiển thị `tank.name · style · N cá`.
7. `game/export_presets.cfg`: preset tên **"Web"**, platform Web, `variant/thread_support=false`, export path `../frontend/public/aquarium/index.html`,
   vram texture compression for desktop on, html canvas resize policy adaptive, không dùng PWA.
8. `game/.gitignore`: `.godot/`, `build/`.
9. `game/README.md`: lệnh chạy editor, chạy headless import, export Web.

## Phần B — React (`frontend/`)
1. `tailwind.config.js`: **thêm** namespace màu mới `cozy` (KHÔNG sửa/xoá các key cũ như `aqua`, `neon`):
   `cozy: { bg:'#EAF6F2', water:'#B8E1D5', wall:'#76B5A5', cream:'#F9F5E9', ink:'#35574F', accent:'#F2B77E' }`.
2. `src/pages/AquariumView.jsx`: route bảo vệ `/tanks/:id/aquarium` (thêm vào `App.jsx` như `/tanks/:id`).
   - Lấy dữ liệu bằng `useQuery` gọi `api.get('/tanks/'+id)` (giống TankDetail).
   - Hàm thuần `toTankSceneDTO(data)` ở `src/aquarium/toTankSceneDTO.js` chuyển dữ liệu hiện có sang DTO plan.md 9.2
     (Phase 0: `speciesKey` = slug hoá tên tiếng Anh/tiếng Việt nếu chưa có; `render` mặc định `{canvas:64, bodyPx:38, swimZone:['mid'], behavior:'wander', speed:1}`;
     `style` = `tank.style ?? 'nature'`; `water` lấy waterLog mới nhất; `care.overdue` từ careTasks chưa done có `nextDue` < now).
   - `<iframe src="/aquarium/index.html">` khung 16:9 responsive, nền `cozy.bg`, bo góc, viền `cozy.ink`.
   - Hook `src/aquarium/useGodotBridge.js`: nghe `message` từ iframe (kiểm `event.origin === window.location.origin` và `event.source === iframe.contentWindow`),
     khi nhận `ready` → gửi `{type:'scene:load', payload: dto}`; khi dto đổi và đã ready → gửi lại. Log các message khác ra console.
   - Nếu `/aquarium/index.html` chưa build (iframe 404) → hiện thông báo thân thiện hướng dẫn chạy lệnh export (kiểm bằng `fetch(..., {method:'HEAD'})`).
   - Thanh trên: tên bể, nút quay lại `/tanks/:id`, màu `cozy`.
3. Trong `src/pages/TankDetail.jsx`: thêm 1 nút/link "🐠 Xem bể 2D" tới `/tanks/:id/aquarium` ở khu tiêu đề (thay đổi tối thiểu, không refactor file).
